DAWNRISE — Browser Prototype v0.1

Open index.html in Chrome on your Android phone. Rotate the phone to landscape.
If Chrome blocks local-file features, host the folder on a static HTTPS site.
No external libraries or network connections are required by the game.

Controls:
- Touch: joystick at lower left; weapon button at upper right; tap any upgrade card.
- Xbox controller: left stick to move; X to switch sword/bow/wand; D-pad left/up/right to select an upgrade; A to confirm.
- Keyboard: WASD / arrows to move, X to switch weapons, 1/2/3 to choose upgrades.

Features: scrolling procedural meadow, ruined watchtower, goblins and orcs,
automatic melee/ranged attacks, XP and 3 upgrade choices, health, pause,
local best-score saving. This is an early prototype with placeholder pixel graphics.

Note: Browser Gamepad API support varies by browser and requires the game window
be focused; if the controller does not respond, tap the game screen once.
